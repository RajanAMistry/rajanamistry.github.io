# Rajan Mistry — Portfolio

A simple, accessible, and print-friendly portfolio for Rajan Mistry, a software engineer based in Pune, India.

## What this site includes

- A concise professional introduction
- Selected product and engineering impact
- Work experience from 2013 to the present
- Frontend, quality, product-engineering, and backend skills
- A print stylesheet for saving the page as an A4 résumé

## View locally

The site uses plain HTML and CSS, so it does not need a build step.

```sh
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).

## Print as a résumé

Select **Download résumé** for the ready-made A4 PDF. The webpage also has a print stylesheet, so the browser’s print command removes navigation and decorative elements automatically.

## Project structure

```text
index.html              Portfolio content and structure
css/custom-styles.css   Screen, responsive, and print styles
assets/                 Social and image assets
output/pdf/             Downloadable résumé
```
